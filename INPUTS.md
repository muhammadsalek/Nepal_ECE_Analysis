# Inputs required for reproduction

## Microdata (DHS - restricted)
- Nepal DHS 2022 Individual/Children recode (e.g., NPPR82FL.DTA) - register/download from https://dhsprogram.com
- Place in: data/ or set path via global/variable

## Derived data
- BDHS_Nepal_Child_Clean.dta (created by Data management.do)

## Spatial (for maps)
- Nepal province shapefile (referenced in Salek.R) - not present in repo

## Tables
- ECE_division_pct.xlsx (referenced in Salek.R) - not present in repo

## Notes
- Raw DHS microdata cannot be redistributed. Follow DHS Program terms of use.
